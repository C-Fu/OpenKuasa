## Screen & Component Interaction Contracts

### 1. Header Integration & Trigger Button (`ThemeSelector`)
- **Mount points:**
  - `src/components/app/app-topbar.tsx` (replaces `ThemeToggle` alongside search, help, notifications, user avatar).
  - `src/components/marketing/marketing-header.tsx` (replaces `ThemeToggle` in marketing navigation).
  - `src/components/account/account-shell.tsx` (replaces `ThemeToggle` in account settings header).
- **Trigger Element:**
  - Radix `PopoverTrigger` wrapping a Ghost `Button` (`size="icon"`).
  - Normal sizing: 36px (`size-9`), mobile sizing: 44px (`max-md:size-11`).
  - Icon: Lucide `Palette` (`size-5`).
  - Active indicator dot: `span.absolute top-2 right-2 size-1.5 rounded-full bg-primary`.
  - Accessible name: `aria-label="Customize theme & appearance"`.
  - Tooltip: `"Customize theme & appearance (current: {Theme Name})"`.

### 2. Floating Theme Selector Popover (`src/components/theme/theme-selector.tsx`)
- **Popover Dimensions:** Width 352px (`w-88`), max-height `calc(100vh - 96px)`, portal mounted to `document.body`, `align="end"`, `sideOffset={8}`.
- **Persistent Interaction:** The popover MUST remain open upon clicking any theme card or mode button so users can compare multiple themes back-to-back without reopening the menu.
- **Layout Structure:**
  1. **Header (36px):**
     - Section title: "Design Systems" (`text-sm font-semibold`).
     - Search filter input: Compact `Input` (`h-8 text-xs placeholder: "Search 12 themes..."`) with instant keyword filtering.
     - Category Tab Rail: 4 segmented tabs (`Modern`, `Datacenter`, `Technical`, `Retro`).
  2. **Body (Scrollable Grid, max-h-72):**
     - 2-column grid (`grid grid-cols-2 gap-2 p-1`).
     - Mini Mockup Cards (`ThemeMockupCard` variant `mini`, 72px height).
  3. **Footer (44px):**
     - Quick Mode Switcher button group: `Light`, `Dark`, `System`.
     - Displays inline locked-mode banner when an active theme requires dark mode ("Theme requires dark mode").
     - Keris slice trigger on mode change.

### 3. Mini Mockup Card Contract (`src/components/theme/theme-mockup-card.tsx`)
Each card renders an authentic miniature UI representation matching the theme's defined palette:
- **Frame:** Rounded container (`rounded-lg border text-left cursor-pointer transition-all hover:scale-[1.02] focus-visible:ring-2`).
- **Active State:** When `preset === activePreset`, render an active border (`ring-2 ring-primary border-primary`) and checkmark badge in the top-right corner.
- **Internal Elements:**
  - Top header strip (4px height) with primary accent dot.
  - Sidebar strip (12px width) simulating app navigation.
  - Miniature content card with mock text rule and miniature button pill.
  - Bottom theme title label (`text-xs font-medium truncate`) + optional dark-locked moon icon.

### 4. Dedicated Settings Gallery Route (`/account/appearance`)
- **Route:** `src/app/account/appearance/page.tsx` wrapped by `AccountShell`.
- **Navigation Registration:** Registered in `src/config/account-nav.ts` under the first `Account` section:
  ```typescript
  { label: 'Appearance', href: '/account/appearance', icon: Palette }
  ```
- **Page Layout:**
  1. **Page Header:**
     - Title: "Appearance & Themes" (`text-2xl font-bold`).
     - Subtitle: "Choose a curated design system and display mode for your workspace."
  2. **Top Mode Card (`Card`):**
     - Title: "Interface Mode".
     - Description: "Select your preferred light or dark mode behavior."
     - Radio / segmented cards: `System Default`, `Light Mode`, `Dark Mode`.
     - Live Keris slice animation feedback upon selection.
  3. **Theme Gallery (`12-Card Grid`):**
     - Responsive grid: `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6`.
     - Large Mockup Cards (`ThemeMockupCard` variant `large`, 144px preview height):
       - Authentic preview canvas with real theme typography sample ("OpenKuasa Enterprise").
       - Swatch strip: 4 color chips showing Primary Brand, Neutral Surface, Accent, and Border.
       - Archetype badge (e.g. `Malaysian Jade`, `Hypervisor Amber`, `Phosphor CRT`, `Swiss Monospace`).
       - Theme Name & Description text.
       - Primary CTA Button: "Active Theme" (disabled outline with check) or "Apply Theme" (primary button).

### 5. Signature Keris Slice Animation Contract
- Both theme preset switching and light/dark toggling MUST invoke `sliceTheme(callback)` from `src/components/theme/keris-slice.ts`.
- The callback synchronously invokes `saveThemeState(preset, mode)`.
- If the selected theme specifies `lockedMode: 'dark'`, the callback automatically promotes mode to `'dark'`.
- Respects `prefers-reduced-motion` (instant switch if reduced motion requested).
